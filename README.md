# Живые обои: Природа

Живые обои для Android: дождь, снег, океан, костёр, листья, северное сияние, светлячки, небо.

## Как получить APK через GitHub (без программирования)
1. Зарегистрируйтесь на github.com и создайте новый репозиторий (New repository).
2. Нажмите «uploading an existing file» и загрузите всё содержимое этой папки (включая скрытую папку `.github`).
3. Откройте вкладку **Actions**, дождитесь зелёной галочки у сборки «Build APK» (3-5 минут). Если не запустилась — «Run workflow».
4. Откройте завершённую сборку, внизу в разделе **Artifacts** скачайте `NatureWalls-apk` (zip), распакуйте — внутри файл `.apk`.

## Или через Android Studio
Откройте папку как проект, дождитесь синхронизации и выберите Build → Build APK(s) (вариант release).

## Установка на телефон
1. Скопируйте `.apk` на телефон и откройте его. Разрешите установку из неизвестных источников, если спросит.
2. Откройте приложение «Живые обои: Природа», выберите сцену и нажмите кнопку установки обоев
   (или: долгое нажатие на рабочий стол → Обои → Живые обои → «Живые обои: Природа»).
3. Нажмите «Установить обои».
